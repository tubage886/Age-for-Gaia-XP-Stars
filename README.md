# Gaia XP Stellar Age Catalog

This repository presents the catalog of stellar ages derived by a **NGBoost-based
model** for **15,175,107 stars** from the Gaia DR3 low-resolution XP
spectrophotometry.

## 📄 Associated Paper

The data in this repository correspond to the following paper:

> **Hou et al. (2026), "Probabilistic Stellar Age Estimation for Gaia XP Stars
> with NGBoost"**
>
> Xiaokun Hou, Wenbo Wu, Gang Zhao, Haining Li, Jingkun Zhao

- 📎 Paper: [arXiv:2607.17932](https://arxiv.org/abs/2607.17932)

✅ **This paper has been accepted by the 9th International Conference on Pattern
Recognition and Artificial Intelligence (PRAI 2026), and is currently in press
(awaiting publication).**

If you use this catalog in your research, please cite the paper above.
